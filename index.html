03 / ALGORITHM INFORMATION

What is IDDLS?

Iterative Deepening Depth-Limited Search combines depth-first exploration with progressively increasing depth limits.

The algorithm starts with a depth limit of zero. If the goal is not found, it repeats the search with a larger limit until the goal is reached or the search space ends.

Working Principle

  1. Begin with a depth limit of zero.
  2. Perform depth-first search without exceeding the limit.
  3. If the goal is not found, increase the depth limit.
  4. Repeat until the goal is found or the search ends.

Advantages

  • Uses less memory than breadth-first search.
  • Finds a shallowest solution for unit-cost moves when the search is complete.

Limitations

  • Revisits states across depth-limit iterations.
  • Can be expensive for large search spaces.

Completeness and Optimality

IDDLS is complete for a finite branching factor when the depth limit increases sufficiently. With equal-cost moves, it finds a solution with the fewest moves.

Time and Space Complexity

For branching factor b and shallowest solution depth d, typical time complexity is O(bd) and space complexity is O(bd), excluding additional storage used by the visualizer.
